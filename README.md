# orcamento-horas-simples

Versão reduzida do "Detalhamento do Orçamento de Horas" Sankhya.

Diferença para a `orcamento-horas-docx`: sem fases de alinhamento, homologação e
documentação; sem resumo consolidado; sem pontos a definir; sem escopo negativo.
O total é a soma dos itens de desenvolvimento, ditados pelo usuário — esta skill
não estima horas.

Gerador, schema, paleta e assets DSTECH v.3 são reusados da `orcamento-horas-docx`;
aqui ficam só o SKILL.md e o JSON de exemplo.

Acionadores: "documento simples de orçamento de horas", "orçamento de horas simples",
"orçamento simples", "versão simples do orçamento".
